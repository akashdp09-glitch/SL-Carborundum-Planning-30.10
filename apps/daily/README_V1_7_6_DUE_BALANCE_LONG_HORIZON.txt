SL PPC DAILY PLANNER V1.7.6 — DUE-DATE FIRST + WORKLOAD BALANCE + LONGER HORIZON

CONTROLLED BASELINE
- Based on V1.7.5 Long-Term MPS/MRP.
- Capacity workbook, lead-time logic, MPS/MRP, Plan 2026 mapping, firing anchors and routing are preserved.

PLANNING THUMB RULE
1. Protect due date first.
2. Never exceed verified process capacity/resource availability.
3. If a day/resource would otherwise be underutilized, pull the next feasible lower-priority / farther-due WO to use the remaining capacity.
4. Lower-priority/far-due work is never allowed to displace executable earlier-due work.
5. This creates smoother workload while keeping delivery protection as the first decision rule.

HORIZON
- Default daily plan = 30 days.
- User can select 7–365 days.
- Longer horizon is optional; 30 days remains default for normal operation.

TRACEABILITY
- Daily plan rows now contain Planning Priority Class and Planning Policy fields so balance-pull work is visible/auditable.
