# V16.29-rc29.17 — numbered Daily Status, photo audit reports, mobile network behavior

## Changes
- Daily Status workbook names beginning 1–6 now map to Preparation, Mixing, Forming, Firing, Grinding/Cutting, and Packing; explicit section names remain supported. The same mapping is used when the Daily Planner reads saved sources.
- Mobile and desktop audit reports show photo evidence for latest audits, plus an audit summary by observed section. The downloadable desktop workbook adds a Photo Index with the audit row, photo filename, and host path. The mobile gallery uses lazy-loaded thumbnails.
- Mobile server listener is confirmed on all host interfaces (`0.0.0.0`); authenticated users can submit from different reachable client IPs, with records saved under the configured host D: `CENTRAL_DATA`. No client-IP allowlist is present.
- Existing login remains required to preserve operator attribution and audit traceability. Off-network access still depends on company network/firewall/router/NAT/VPN reachability and is not opened by the software.

## Verification
- Python syntax compilation passed for the changed Python modules.
- Synthetic SQLite test passed for audit report photo filename, quantity unit, and latest-record loading.
- Numeric section-prefix mapping assertions passed. Full pytest suite was not available; Jinja2 template rendering and real Windows/phone/network tests were unavailable here.
- No live audit database or photos are included or modified by the package.
