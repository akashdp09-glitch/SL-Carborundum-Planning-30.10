SL PPC DAILY PLANNER V1.9.27
17 Sep 2026

Compatibility update for Firing Planner F12R+ Excel output.
- Accepts bilingual Operator Print headers.
- Accepts Loading Date / วันที่เข้าเตา and Firing Finish Date / วันที่เผาเสร็จ.
- Accepts Planned Qty (pcs) / จำนวนแผน (ชิ้น).
- Ignores extra Firing Planner columns safely.
- Preserves Test Work, Product Code, Customer, Category, Kiln, Program and Due Date metadata when present.
- Legacy firing output formats remain supported.
