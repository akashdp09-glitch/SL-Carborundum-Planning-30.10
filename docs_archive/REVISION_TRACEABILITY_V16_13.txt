DESKTOP WORK ORDER LOOKUP FIX
- Previous implementation opened the active Plan workbook again on each Home rerun, assumed WO was in column A, and hid every exception by returning None. This led to a generic “not found” for missing files, schema changes, and read errors, and could be slow while typing.
- New desktop lookup uses the already loaded Plan dataframe, dynamically matches the ProductionCode header, normalizes case/punctuation, strips SLWO:/WO: prefixes and URL wrappers, and offers in-memory partial suggestions. It reports missing Plan, no match and lookup error separately. Successful results identify the source Plan row.
- Verified with user reference `Plan 2026-2-Update-240926.xlsx`, sheet `แผนการเผา`, header row 3; 3,409 data rows. Exact normalized WO `P025-230926` found in Plan row 3412; prefix `P025` returned suggestions; typed, dashless, `SLWO:` and URL forms normalize consistently.
