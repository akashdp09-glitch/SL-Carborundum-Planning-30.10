# V16.29-rc29.15 — WIP graphs, dashboard spacing and recovery clarity

## Changes
- Moved the cached local hero image and logo above the Home breadcrumb, reduced its height, shortened the language note, and reduced top spacing. The source-file trace table now starts collapsed to reduce Home scrolling.
- Added a due-month open/closed product-category stacked graph to the optional Home dashboard analysis. Open future orders are explicitly labelled as scheduled demand, not overdue backorders; a separate count/pcs summary uses the Thailand-date overdue rule. Category F is grouped with P.
- Kept Recovery as a separate Daily Planner destination. Replaced the confusing shared-calculation message with a short saved-schedule status and added full-day section utilization checks, 100%/103% reference lines, and a separate Mixing mills/day chart. These charts reconcile to the saved plan; they do not add duplicate demand or rebuild it.
- Added mobile WIP graphs in the Report tab from the same active Production WIP section workbooks as desktop: WIP tonnes by section and category, section WO-record counts, and source filename/import time. Added a separately labelled open-order-balance-by-process graph and retained the physical audit graphs. These are distinct measures; order balance is not a physical count.
- Focused F1 search for “how to read product specification” and equivalent Thai prompts on the cited SPEC explanation; reduced the default help cards and moved suggested questions into a collapsed list.
- Updated requirements to permit compact, read-only mobile WIP graphs without moving planning engines or workbook editing to mobile.

## Data preservation and source basis
- No live `CENTRAL_DATA`, database, QR labels, audit records or photos are included or modified by this package.
- Mobile Production WIP graphs read active source files under `CENTRAL_DATA/PRODUCTION_WIP`; source names and recorded import times are shown. Missing source workbooks are reported as missing, never as zero.
- The mobile open-order-balance graph is calculated from work-order quantity less the largest recorded production completion, grouped by last scanned process. It is not a physical WIP count.
- Home due-month chart comes from active Plan-2026. Only the separate overdue summary is classed as backorder.
