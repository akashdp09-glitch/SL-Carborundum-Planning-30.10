SL PPC FIRING PLANNER V1.9.18F7 — POSITIVE PUSH/PULL PLANNING

Planning philosophy:
1. Due date is first priority.
2. Build best compatible kiln combination using height, occupied volume and program weight capacity.
3. Balance firing workload across every working day; normal target up to 2 vitrified starts/day excluding T0. Resin kilns are independent resources.
4. Do not omit a future kiln merely because parts are not ready. Missing pcs become explicit WO-specific Preparation/Mixing/Forming PUSH requirements with required-by dates.
5. Readiness remains the shop-floor RELEASE gate; physical/furniture validation remains mandatory.
6. After firing, Daily Planner uses PULL logic for QC/Grinding or Cutting/Packing.
7. Graph/table fields expose Ready pcs, MAKE pcs, height %, volume %, program weight %, target occupancy and upstream PUSH signal.
