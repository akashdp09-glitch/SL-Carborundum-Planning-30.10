DRYING IN DAILY PLANNING
The category Lead Time row 6 provides a general post-forming oven/drying time gate: S=2, T=3, P=3, R=2, M=1 days; PB does not use this step. It gives no dryer capacity, and the source does not say whether category days are calendar or working days; the planner's readiness offsets use working days. Q26-009 reference WO P005-110826 is separately source-linked to 4 calendar days drying plus 2 calendar days pre-firing checks. RC29 applies those timings only to that exact WO. See F1 → “Drying time and pre-firing checks” and knowledge\PROCESS_EVIDENCE_DRYING_2026-10-06.json.

PREVIOUS FIRING PLAN INPUT
On the Firing page, upload either the complete firing workbook or the smaller Operator Print sheet issued to Production. The print-only sheet must contain Work Order, Kiln, Loading Date, planned quantity, and Firing Complete / firing finish date. It is used as the shared previous firing source by Firing and Daily. A file missing required columns is rejected before it can replace the active source.

STOCK-ON-HAND MATERIAL STATUS
Open Home → Quick access → Material status, or Planning → Stock-on-Hand Material Status. This standalone page reads the active shared Stock on Hand workbook directly; it does not require creating a Daily Plan. It displays shortage/urgent/watch/OK counts and a searchable table with source sheet, Excel row, balance column and unit. The CSV export includes source workbook, revision, import time and SHA-256. Upload a revised stock workbook once from the page source panel; the other modules reuse it.

HOME SHORTCUTS
🚨 Backorder / Delivery Risk and 🧯 Risk & Backorder Recovery Plan are direct Home / Quick Access links and remain under Reports & Tools.

DATA SAFETY
The RC29.30 ZIP contains application code, not your live CENTRAL_DATA. Before first launch, copy your existing complete CENTRAL_DATA folder beside the new program; do not replace the only copy. This update does not change the established QR payload, regenerate issued QR labels, or require reprinting them. Existing labels remain valid. Keep the original data folder and old program folder until DB rows, audits, photos, QR scan images, source history and exports are confirmed in the new app. This release candidate has passed source checks only; it still requires factory-PC and real-phone verification.
