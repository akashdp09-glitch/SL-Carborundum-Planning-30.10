SL CARBORUNDUM SMART FACTORY CENTER — V16.16
Prepared 2026-10-02 (Asia/Bangkok)

START
1. Run INSTALL_REQUIREMENTS.bat on the Windows server, then START_SL_CARBORUNDUM_PLANNING_CENTER.bat.
2. From Home → Upload / Replace Source Files, upload the current Plan-2026, Stock on Hand, Sales Forecast, Firing Plan, Packaging Standard, and other current source workbooks. The program never assumes this package contains today's live business files.
3. In Daily Planner → Daily Status, upload each department's own workbook into its separate box: Preparation, Mixing, Forming, Firing, Grinding, Packing. The worksheet tab name is the daily reporting date; date cells inside the workbook are not authoritative.
4. Keep the two KPI reports separate in their own upload boxes.
5. For a new sales release, use Home → “RP → Work Order → Cover Sheet → Plan 2026”. Upload RP, review detected values, fill missing/uncertain fields, assign the controlled Work Order number, check the material/process/capacity/schedule/packaging gates, then download the draft packet. Copy reviewed data into your approved controlled blue-sheet cover template and release only through your normal approval process.
6. The draft packet includes the Plan-2026-format sheet, RP_SOURCE provenance, WORK_ORDER_DRAFT, COVER_SHEET_DRAFT, PLANNING_BASIS, MATERIAL_FEASIBILITY and READINESS_CHECK. The software package does not include the current controlled blue-sheet cover template; the draft cover sheet is a data handoff, not a replacement for that approved form.
7. Daily Planner left menu now expands categories in place. Open a category and select the exact page; Direct Access remains available for frequently used pages.
8. Daily Planner → Mixing Mill Plan vs Actual compares plan batches and kg with source actuals and CAP ผสม capacity. Unknown machines and capacity overages are visible review items, not silently accepted capacity.
9. Home → Work Order QR/Audit generates IP-independent SLWO:<WO> labels. The QR label itself contains no server address. The phone-camera connection QR is a separate link to the app; mobile live capture requires HTTPS, camera permission and a reachable server. Scan/audit photographs are saved separately with source/result metadata.

SPEED AND INTERFACE CHANGES
- Plan-2026 reader is bounded to the known A:IA field range (235 columns). The new-plan engine previously read the formatting-inflated worksheet width (~15,988 columns); it now reads the mapped 235 columns.
- Daily Planner navigation is an expandable left hierarchy. Every subpage link is range-checked so an invalid navigation map cannot raise IndexError.
- RP parsing now detects document number, customer, product/spec, size, qty, reference WO, material/bond, machine, firing program, packaging count, paper-wrap count and explicit no-brand-mark instruction when present in ordinary text cells.
- Exact source upload filename, renamed stored filename, server location, import time, user/page, workbook modified time when available, file size and SHA-256 are recorded in Home → Uploaded Files & Traceability. The browser does not expose the source PC/phone folder; this is marked as unavailable rather than guessed.
