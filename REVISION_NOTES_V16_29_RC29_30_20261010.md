# V16.29-rc29.30 — direct Stock-on-Hand material status

## What changed

- Added a standalone **Stock-on-Hand Material Status** page in Planning. It reads the current shared Stock on Hand workbook directly and can be opened without creating or recalculating a Daily Plan.
- Added a Home Quick access shortcut, a searchable function entry, a Planning navigation entry, and an F1 help answer so the status is not buried inside the Daily Planner.
- The page shows counts for shortage, zero/urgent, watch, and OK records; a status filter; material code/name search; and a full source-linked table. CSV export records source workbook, source revision, import time, and SHA-256.

- The page uses the existing `STOCK_ON_HAND` source revision and contextual upload manager. Upload the stock file once; no duplicate upload or separate stock database was added.
- Renamed the existing Daily Planner submodule to **Plan Material Check** to distinguish its plan/BOM/material feasibility check from the standalone stock-position status.

## Status meaning

- `SHORTAGE`: source balance is negative.
- `ZERO / URGENT`: source balance is zero while open-order quantity is positive.
- `WATCH`: positive source balance below 25% of open-order quantity.
- `OK`: other positive source balance.

These are stock-position screening statuses, not a work-order release decision. A WO-specific material check also depends on BOM/recipe, need date, inbound material, lab holds, and reservations. The page shows the stock workbook's import time separately from its own stock-count/as-of date; the software does not infer that date.
