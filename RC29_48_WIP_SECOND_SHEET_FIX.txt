V16.29-rc29.48 — Production WIP reads the second-sheet summary

What changed
- Production WIP now reads the second worksheet in each uploaded section workbook. The summary row values “ยังไม่ปิด” (reported open WO count) and “GW (Kg)” are the WIP values used in desktop, home/dashboard, mobile report and downloadable report views.
- Total WO minus Closed WO is retained as a check only. Conflicting rows stay visible and are flagged; the software does not replace the reported open count or invent a category from detail rows.
- Category F is displayed as P. Workbook name, import time, source sheet and source cell references are retained.
- Mobile WIP wording now identifies the displayed count as the reported open-WO count. F1 Help explains this rule in English and Thai.
