SL PPC DAILY PLANNER V1.8.1

Controlled changes
1. CAPACITY_DATABASE.xlsx replaced with the user supplied 11-Sep-2026 revised capacity master.
2. Daily scheduling continues to read machine/status/schedule/manpower dynamically from that workbook.
3. Selected Work Order Gantt now has a direct Excel download. Excel contains Gantt Data, Due Date Review and a date-grid Gantt Chart; actual is cumulative progress only because Plan2026 does not provide dated actual history for every process.
4. MPS is now explicitly an aggregate master production schedule: Sales Forecast vs aggregate demand/MPS vs normal capacity-feasible Possible Plan.
5. Monthwise feasibility, capacity shortfall, primary constraint, risk and suggested capacity/investment action are shown.
6. Category-wise and size-wise MPS tables/graphs show forecast/demand, possible plan, shortfall and feasibility.
7. Normal capacity is used first; OT/manpower/outsource/investment remain recovery actions. Demand is not silently deleted when capacity is tight.
