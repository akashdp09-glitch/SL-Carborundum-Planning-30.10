# V16.29-rc29.19 — shared backorder definition and capacity evidence

## What changed
- Home, the Backorder page, Daily Planner backorder views, the TV/meeting backorder summary, and MPS use a Thailand-local as-of date and the same strict rule: an order is overdue only when it is open, has a positive remaining balance, and its due date is before today. Due today is not overdue. Future open orders, including 2027, are not labeled backorders.
- Product category F is normalized to P; repeated source/process rows are collapsed to one WO so quantities do not multiply.
- Long-range MPS uses the actual as-of date for backorder classification instead of the selected horizon month. Future MPS demand remains separate.
- Recovery analysis now explains that it reconciles the existing unified daily plan and does not add a duplicate quantity. The capacity evidence shows the listed recovery allocation, whole-day load, controlled capacity, implied headroom before those allocations, remaining headroom, excess tonnes, and Mixing mills/day. WOs without schedule rows are marked NOT SCHEDULED; the page displays the current unassigned section/date capacity outlook without pretending to insert or approve a recovery slot.
- The Backorder page separates the past-due chart from the collapsed Future Open Demand view.

## Verification
- Python syntax compilation: hub, Daily Planner, MPS engine, shared backorder helper and recovery helper passed.
- Seven focused unittest cases passed for date cutoff, future 2027 exclusion, closure, category F→P, duplicate-WO protection, existing-plan reconciliation, capacity headroom and infeasibility behavior.
- Streamlit is not installed in this build workspace, so interactive launch, live factory workbook reconciliation, Windows startup and on-device acceptance were not run.

## Important operation note
The Recovery page is a reconciliation and capacity-evidence view. It does not automatically commit new WO rows into the daily schedule. An unscheduled WO must receive a dated, route-valid, capacity-feasible allocation in the Daily Plan before the recovery is treated as committed.
