SL PPC Daily Planner V1.7.0

Key confirmed changes:
- Revised Plan 2026 default column map (10-Sep-2026), editable in GUI.
- CP > 1 = Cutting route. CP <= 1 and Category S/T or Honing/Honning/Segment variants = QC -> Packing (no grinding/cutting).
- Cleaning removed as a separate process; included in firing cycle/cooling/cleaning time.
- PMxxxA/PMxxxB same-date two-layer pairs synchronized for Preparation/Mixing/Forming to the later feasible date.
- 7.40 normal productive hours/day shown; OT suggestion table added when plan load exceeds indicative normal-day capacity.
- Delivery risk expanded: due date, full order, current WIP/status, bottleneck, projected finish, detailed reason + graph.
- Interactive stock graphs: Order on Hand vs stacked Stock in Hand + Under Receiving + Under Test.
- Interactive MPS category-wise and size-wise graphs.
- Plan vs Actual analysis tab using all rows including closed rows. With current mapped fields, period views are due-date cohorts unless dated daily actual is uploaded; no historical process dates are fabricated.
