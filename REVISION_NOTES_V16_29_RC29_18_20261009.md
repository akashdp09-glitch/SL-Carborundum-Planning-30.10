# V16.29-rc29.18 — visible Daily Plan create/update control

## Fix
A restored/saved calculation previously moved the only create/recalculate button into a collapsed expander. Since a saved plan is restored on navigation and startup, users saw an old plan but could not readily find the action to create a fresh one.

The Create / Update Daily Plan button is now visible whether or not a saved calculation exists. The page shows the saved calculation timestamp and compares its recorded input/settings fingerprint with the current one. When they differ, it warns that the displayed result may be old and should be recalculated before release. The saved calculation is replaced only after a new calculation passes source consistency checks; if the new run fails, the previous snapshot remains available.
