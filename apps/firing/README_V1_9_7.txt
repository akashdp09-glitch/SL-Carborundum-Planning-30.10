SL PPC FIRING PLANNER V1.9.7 — PERFORMANCE + MAPPING + TWO-LAYER

1) Revised Plan 2026 default column mapping (10-Sep-2026) is built in and editable in the GUI.
2) Existing fast 30-day allocation architecture and selected-load exact physical validation are preserved.
3) A/B two-layer WOs are combined before Firing as one physical part. Conservative rule: firing readiness = weaker layer, gross weight = A+B, thickness = A+B where numeric, final quantity is limited by both layers. Audit tab shows source WOs.
4) Added Firing Performance tab with interactive Daily/Weekly/Monthly utilization graphs: geometric occupancy, weight utilization, height utilization when available, and kiln comparison. Missing height data is shown as unavailable; no value is invented.
5) Operator print keeps Angsana New preferred for Thai and now uses a larger/higher-resolution 3-view pattern in Excel/PDF.
6) Operator sheet continues to show Date, Kiln, Program and Load ID prominently.
7) Column mapping used and two-layer combination audit are visible in the application.

Important mapping note
The supplied mapping places BOTH Mixing Status and REJECT at FH. Firing readiness uses FH as Mixing Status. REJECT is audit-only unless the mapping is corrected later.
