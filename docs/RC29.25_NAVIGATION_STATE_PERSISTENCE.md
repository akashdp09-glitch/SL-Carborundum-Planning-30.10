# V16.29-rc29.25 — login, source and analysis persistence on navigation

Fixed hub links that navigated to `?page=...` without carrying the signed `auth_ticket`. Those full-page navigations could open a new Streamlit session and appear to sign the user out. Internal hub links now use the shared ticket-preserving URL helper; the deliberate SIGN OUT / SWITCH USER action ends the hub login. The signed browser ticket now lasts 30 days, matching the expected long-lived operator/planner session; it contains no password.

Uploaded workbooks are saved into `CENTRAL_DATA` / Source Manager revisions and remain active when page upload widgets clear after leaving the page. The Files & Traceability sidebar lists active copies and revision details. A blank uploader is ready for another revision; it is not evidence that the active source was removed.

The Daily Planner continues to restore its last successful calculation from `CENTRAL_DATA/CACHE/daily_result.pkl` and dated `DAILY_PLAN_SNAPSHOTS`. Page navigation does not run replan/reanalysis or clear whole-session state. A new input revision or the user-selected Create/Replan action is needed for a new calculation.

Validation: hub and state/auth modules compile; static checks found no direct internal `?page=` anchors that omit the ticket; source upload and daily plan snapshot persistence paths remain present. Interactive Windows/browser session and multi-tab tests were not available in this workspace.
