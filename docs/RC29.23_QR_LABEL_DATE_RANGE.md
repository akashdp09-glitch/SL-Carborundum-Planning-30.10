# V16.29-rc29.23 — QR label date-range fix

The Open Work Order QR Labels date pickers no longer restrict both ends to the only date present in the active plan (or to today when no due dates parse). They accept dates from 2000-01-01 through 2100-12-31. The displayed/generatable rows remain limited to open work orders with positive remaining quantity in the active Plan-2026, and the filter uses the current due date. A selected range with no matching active-plan rows correctly returns zero labels.

Validation: Python compilation passed. Synthetic filtering checks passed for past, present, future and full-plan ranges. Live workbook, Windows UI and sticker-printer output were not available for validation.
