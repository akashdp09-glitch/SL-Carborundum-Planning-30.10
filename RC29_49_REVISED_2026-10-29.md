# RC29.49 revised implementation — 2026-10-29

## Changes in this revision

### Planning KPI
- Added automatic recognition of the revised October Planning KPI evidence workbooks.
- KPI-PL-07 October result: 448 / 448 = 100%.
- KPI-PL-08 October result: 286 / 286 = 100%.
- Blank/zero-target days are treated as N/A, not failures.
- October closed-job workbook is shown as operational evidence (250 closed items) without inventing a KPI target.
- Added source-manager slots for monthly Planning KPI execution and job-closure evidence.

### Firing Planner
- Added bounded same-program candidate screening to reduce repeated expensive physical checks.
- Candidate scan is normally limited to the earliest 120 due-date candidates, with a fallback scan only when no feasible kiln is found.
- Same-program physical candidate window is bounded and widened only when the first window cannot approach the kiln target.
- Added utilization-gap fields to the firing load output:
  - Utilization Gap %
  - Utilization Status
  - Planning Gap Reason
- The planner continues to protect due dates and physical/furniture constraints; it does not create artificial full loads.

### Navigation
- Internal Planning Center hyperlinks now use an explicit same-document relative path (`./?page=...`) for better reliability when the application is hosted behind a reverse proxy or sub-path.

### Learning material
- Added `MANUAL_PROJECT_DEVELOPMENT_GUIDE.md` covering architecture, database structure, firing-planning data model, KPI model, QR/WIP architecture, performance design, testing and a manual learning roadmap.
