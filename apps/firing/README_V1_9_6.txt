SL PPC FIRING PLANNER V1.9.6 — ANGSANA THAI OPERATOR PRINT

Changes from V1.9.5:
- Thai operator-sheet font changed to Angsana New in Excel.
- PDF font registration now prefers Windows Angsana New font files, then falls back to Tahoma/Leelawadee UI.
- Thai title/header/check text sizes increased slightly because Angsana New renders optically smaller than the prior font.
- English remains Arial/Helvetica; Burmese remains Myanmar Text when available.
- No firing allocation, kiln-cycle, due-date, furniture, geometry, occupancy, weight or released-quantity validation logic was changed.

Windows note:
If Angsana New is installed in Windows, Excel/PDF will use it. If it is unavailable, PDF falls back to another Thai-capable Windows font; Excel may substitute an installed Thai font automatically.
