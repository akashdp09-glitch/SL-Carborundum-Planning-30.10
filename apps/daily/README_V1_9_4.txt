REPEATABLE PLANNING RULE
Due Date first -> finite executable capacity -> firing synchronization -> workload balance -> resource utilization.
The same sequence applies to every valid open WO on every planning day. Plan/process date is fallback only when Due Date is missing.
Early completion is allowed. Once earlier-due executable demand is protected, unused finite capacity pulls the next-earliest feasible demand.
No process may pull above controlled daily machine/manpower/material capacity.

STACK GRAPH RULE
Every stacked graph prints one clear TOTAL for the complete stack. Individual segment values are not printed; details remain available by hover/table.
Selected-date dashboard is retained.
